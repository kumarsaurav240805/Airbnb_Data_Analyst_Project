1. Airbnb Data Analysis & Interactive Power BI Dashboard
   
The complete Airbnb data analytics project covered the analysis of listings, prices, room type, neighborhoods, reviews, availability, host, booking habits, and house rules sentiment through Python, SQL, Statistics, and Power BI.
3. Short Description / Purpose
Airbnb Listing Data Analysis Project is based on the distribution of property, pricing, engagement, behavior of customers and hosts, availability and trends in neighborhoods.
Python for Data Cleaning and Exploratory Data Analysis, SQL for Business Analysis, Statistical Data Analysis, Sentiment Analysis and Power BI visualization are used to make sense of the raw data from Airbnb.
Python notebook has 102,599 rows and 26 columns in the analyzed dataset.
4. Tech Stack
The project utilizes the following technologies and tools:
🐍 Python – Data analysis and preprocessing
🔢 NumPy – Numerical computation
🐼 Pandas – Data cleaning and analysis
📊 Matplotlib – Data visualization
📈 Seaborn – Statistical visualization
🗄️ SQL/SQLite – Business analytics
📐 Statistics/SciPy – Statistical and correlation analysis
💬 TextBlob – House-rule sentiment analysis
📊 Power BI – Dashboard and business reports
🧮 DAX – Dashboard calculations and KPIs
 5. Data Source
This data is sourced from the college I go to for an academic project. The data set has 102,599 rows and 26 columns. This data was used for data analysis, getting insights, and visualizations.
5.🔹 Business Problem
The Airbnb websites are sources for a massive quantity of data on listing and hosts. The data is in its raw form and hence, it is hard to get answers to the following questions:
Which room types prevail on the website?
Which neighbourhoods have many listings?
Price difference based on location and property types?
How do reviews vary among different properties?
Availability of listings differs in what ways?
Are there any connections between host verification and listing features?
What is the correlation between price and review numbers?
Is there any sentiment in house rules?

8.Impact on Business & Insights Gained
📍 Location Insights
This tool can be used to find locations with high concentration of listings and perform pricing comparison based on geographical data.
🏠 Property Insights
Room type insights allow analyzing how Airbnb supply is split between entire homes, private rooms, shared rooms, and hotel rooms.
💰 Pricing Insights
Pricing insights help compare prices for different neighbourhood groupings and room types and also gain geographical price insights.
⭐ Customer Engagement Insights
Review insights help find most reviewed properties and analyze how reviews are connected to prices.
👤 Host Insights
Host insights can be used to analyze reviews, pricing, and room type distribution.
📅 Availability Insights
Availability insights help to separate listings based on low and high annual availability.
💬 House Rules Insights
Sentiment insights provide an extra point of view on the way how hosts communicate house rules.
9. Conclusion
This project on Airbnb Data Analysis is a complete analytics process from data cleaning through feature engineering all the way to SQL and statistical analysis, sentiment analysis, and Power BI interactive visualizations.
These analyses reveal various trends in rooms, neighborhoods, prices, reviews, availability, hosts, and house rules.
